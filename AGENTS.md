# AFTON website instructions

## Project boundary

- This repository contains only the public AFTON website.
- Never mix in FormulLab, FMOC2, `fomull`, `FormulLab-3-`, WorkTwin control-plane code, recipes, formula data, private research, or customer data.
- GitHub is the source of truth for website code and public content.

## v0.1 scope

- Astro static output.
- One lightweight responsive landing page.
- Official `afton.` wordmark asset only; do not retype or approximate the logo.
- CSS-first perceptual field with one controlled visual contradiction.
- No WebGL, Three.js, CMS, database, authentication, payment, waitlist collection, tracking, or FMOC2 integration.

## Visual system

- Contemporary modernist grid, not retro Bauhaus decoration.
- Warm neutral field, graphite typography, muted mineral blue-grey, one faded warm orange accent.
- Preserve asymmetry on mobile.
- Motion must remain subtle and respect `prefers-reduced-motion`.
- Avoid perfume-category clichés: flowers, fog, skin, glossy bottle hero shots, molecules, atoms, neurons, and generic AI gradients.

## Lifecycle

- Branch work is `CANDIDATE` until reviewed.
- Build and Cloudflare dry-run are verification only, not release approval.
- Connect `afton.works` only after the site preview is approved.
