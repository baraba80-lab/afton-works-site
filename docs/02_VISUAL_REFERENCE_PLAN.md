## AFTON generation families
Original work is planned in six families.

1. **FIELD / DIFFUSION**
   Quiet abstract fields, particulate or translucent, with one contradictory event.

2. **FIELD / RESIDUE**
   A visual trace left after an absent object or event.

3. **EVIDENCE / LAB**
   Close physical evidence from a fragrance workspace. Avoid sterile pharma-lab cliché.

4. **MEMORY / DOUBLE**
   One object or scene appears almost duplicated through reflection, crop, or translucent overlap.

5. **MEMORY / MISSING**
   A composition feels complete at first, then reveals one absent or displaced piece.

6. **FIELD / CALIBRATION**
   Two almost-overlapping visual systems with a slight offset, representing population perception versus personal perception.

The complete copy-paste prompt library is in `docs/07_IMAGE_PROMPT_LIBRARY.md`.

## Image-generation rule
Do not request perfume bottles, flowers, smoke, floating molecules, brains, EEG waves, cyber HUDs, or generic luxury-product lighting unless explicitly testing an anti-pattern.

Do not generate AFTON logos or final typography inside the image. Typography is applied in layout later.

## Selection criteria
Score each candidate on:
- immediate beauty
- ambiguity
- AFTON specificity
- material credibility
- crop resilience
- typographic compatibility
- low visual cliché
- potential for lightweight web delivery
- emotional aftertone
