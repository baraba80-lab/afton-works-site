# AFTON — Visual Concept Brief

## Core proposition
**Familiar, but not identifiable.**

AFTON deals with scent as memory, residue, perceptual ambiguity, and the gap between what people collectively report and what one person actually experiences.

## Visual attitude
- contemporary, not retro-Bauhaus
- functional grid with controlled deviation
- architectural, editorial, restrained
- semi-futuristic without sci-fi interface clichés
- cognitive / perceptual rather than literal neuroscience
- molecular behavior rather than molecule diagrams

## Key visual behaviors
Translate scent into behaviors rather than icons:
- clustering
- diffusion
- persistence
- interference
- concentration
- disappearance
- return
- afterimage

## Evidence / Memory image system
### EVIDENCE
Physical reality:
- raw material bottles
- pipettes
- paper strips
- metal trays
- stained paper
- sample vials
- printer labels
- studio tables
- artist collaboration records

### MEMORY
Ambiguous perceptual material:
- extreme crops
- partially repeated images
- translucent overlays
- reflections that split one object into two
- almost-identical compositions with one change
- forms that appear rule-based but cannot be immediately decoded

The site should alternate between EVIDENCE and MEMORY so it never becomes either a sterile lab site or a generic perfume campaign.

## Scent Field
A Scent Field is not a literal formula visualization. It is a generated abstract field whose behavior can later be driven by public sensory axes such as:
- dryness
- warmth
- density
- diffusion
- softness
- sweetness
- mineral character
- persistence

For the temporary landing, the field may be a pre-rendered still or short lightweight loop.

## Color behavior
Do not freeze a conventional brand palette too early.
Use a relationship rule instead:
- mostly neutral field
- restrained scent-specific color
- very small contradictory accent

The contradictory accent should feel intentional but slightly unexplained.

## Typography
Typography should be cold, functional, and highly controlled. Avoid decorative luxury-perfume typography.

Prefer large scale contrast:
- very large primary type
- very small technical metadata
- fewer medium-sized headings

## Temporary landing goal
The first screen is not a full shop and not a conventional COMING SOON page. It should function as the first piece of AFTON's world.

Minimum content:
- afton.
- one core sentence
- one perceptual field image
- minimal status / contact information

No heavy system explanation on the first screen.
