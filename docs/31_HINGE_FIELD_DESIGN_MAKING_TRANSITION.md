# HINGE & RULE — 설계 가능한 목수 / 현장 목공일 전환안

Date: 2026-09-14  
Status: 전략 설계 v0.2 / 창업자 교정 반영 / 세무·노무·건설업 법률 검토 후 파일럿
Applies to: Hinge & Rule business model, feed transition, founder continuity

## 1. 전환 결정

힌지앤룰은 종합 인테리어 공사를 도급받지 않는다. 전체 공사비, 공정, 타 공종 기술자, 현장관리, 하자와 고객 대응을 한곳에 모아 책임지는 방식으로 돌아가지 않는다.

대신 지랭은 **설계하고 판단할 수 있는 목수**로 일한다.

> 목수로 투입된 하루 안에서 현장을 재고, 소비자의 요구를 듣고, 스케치와 CAD로 해법을 만들고, 재료와 예상금액을 산출하고, 발주를 돕고, 직접 연장을 잡아 목공한다. 그날의 정신노동과 육체노동을 나누지 않고 같은 목공 1일 인건비로 계산한다.

오늘 하루가 치수 확인과 계획으로 끝나도 목공 1일이다. 다음 날 구조목공과 설치를 해도 같은 기준의 목공 1일이다. 소비자는 계획과 시공 사이에서 바로 확인하고 수정할 수 있고, 지랭은 완성된 도면을 멀리서 넘기는 사람이 아니라 현장에서 판단을 갱신하는 제작자다.

## 2. 이 모델이 아닌 것

- 기획만 따로 판매하는 디자인 용역
- 도면만 납품하는 설계사무소형 서비스
- 전체 인테리어 일괄 견적과 공사 완성을 약속하는 도급
- 타 공종의 일정·품질·하자·대금을 대신 관리하는 현장관리
- 기술자 비용을 한꺼번에 받아 마진을 붙여 재지급하는 방식
- 무료 견적을 가장한 장시간의 설계·재료 산출

**기획과 디자인만 따로는 하지 않는다.** 현장 스케치, 가구·목공 도면, 재료 산출과 예상금액 검토는 지랭이 실제로 참여하는 목공·가구 작업의 일부다. 그 기록은 해당 현장에서 소비자와 작업자가 사용할 수 있도록 넘긴다.

## 3. 하나의 핵심 상품 — HINGE CARPENTRY DAY

기존 v0.1의 `FIELD DESIGN DAY`, `DRAWING SPRINT`, `SITE TRANSLATION VISIT`는 독립 상품으로 판매하지 않는다. 모두 `HINGE CARPENTRY DAY` 안에서 그날 현장에 필요한 일로 통합한다.

### 한 작업일에 포함될 수 있는 일

- 소비자 요구 청취와 우선순위 정리
- 현장 치수 측정과 기준선 확인
- 현장 손스케치, 노트북 CAD, 가구·목공 상세 정리
- 구조목공과 가구의 제작·설치 방법 판단
- 자재 규격·수량·철물·소모품 목록 작성
- 예상 재료비와 필요한 공수 설명
- 소비자가 직접 주문할 수 있는 발주 목록 정리
- 타 공종 기술자에게 목공과 맞물리는 치수·순서·의도 설명
- 먹매김, 가공, 조립, 구조목공, 현장 제작, 설치와 수정
- 소비자가 현장에서 확인한 변경사항의 즉시 반영

### 과금 원칙

1. 기본 단위는 **목공 1일 인건비**다.
2. 연장을 잡은 시간만 세지 않는다. 측정·판단·스케치·CAD·물량 산출·발주 지원도 같은 작업일에 포함한다.
3. `오늘은 계획만 했으니 무료` 또는 `도면이니 별도 기획비`로 처리하지 않는다.
4. 하루의 시작·종료, 이동·식사·초과시간·취소 기준은 파일럿 전에 정한다.
5. 여러 날이 필요하면 작업한 날짜별로 정산한다. 전체 공사 완성을 전제로 총액을 묶지 않는다.
6. 소비자 요청으로 추가 작업일이 생기면 다음 작업일을 새로 확정한다.

정신노동을 목공에서 빼지 않는 것이 핵심이다. 지랭의 경쟁력은 연장 사용과 현장 판단이 한 사람 안에서 이어진다는 데 있다.

## 4. 가구와 대형 현장 제작

### 작업장 제작 가구

- 작업장에서 가공·조립하고 현장에 납품한다.
- 설계, 도면, 가공, 조립에 실제 투입된 목공 작업일을 기록한다.
- 자재는 원칙적으로 소비자가 승인·주문·직접 결제한다.
- 운송, 양중, 특수 장비가 필요하면 소비자가 해당 업체와 직접 결제하거나 실비를 사전에 승인한다.
- 치수, 마감, 수량, 납품 조건과 수정 범위는 짧은 제작 확인서에 남긴다.

### 현장에서 만드는 대형 가구·구조목공

- 현장 목공 작업일수에 따라 인건비를 받는다.
- 필요한 자재·철물 목록은 지랭이 산출하지만 주문과 결제는 소비자가 한다.
- 완성품 총액을 정해 자재비와 타 공종비를 묶어 받지 않는다.
- 소비자가 현장에서 직접 확인하고 변경을 선택할 수 있다. 변경은 필요한 추가 작업일과 자재로 즉시 환산한다.

가구 제작과 납품은 결과물 책임이 발생할 수 있으므로 `일당`이라는 이름만으로 도급·제작계약 가능성이 사라지는 것은 아니다. 경제적 계산은 작업일수로 하되, 실제 거래 성격과 책임은 파일럿 전에 전문가 검토를 거친다.

## 5. 자재 주문 구조

1. 지랭이 규격, 수량, 대체 가능품, 필요한 납기와 주문 목록을 만든다.
2. 소비자가 목록과 금액을 확인한다.
3. 소비자가 판매처에 직접 주문하고 직접 결제한다.
4. 반품·교환·배송·세금계산서의 당사자도 원칙적으로 소비자와 판매처다.
5. 현장 오차나 변경으로 추가 자재가 필요하면 이유와 수량을 알리고 소비자가 다시 주문한다.
6. 지랭은 자재비를 모아 집행하거나 자재 마진을 숨겨 붙이지 않는다.

발주 지원은 목공 작업일 안의 업무다. 다만 소비자의 계정·결제수단을 임의로 사용하지 않고 최종 주문 승인은 소비자가 한다.

## 6. 타 공종 기술자 직접 연결

지랭은 지금까지 함께 일하며 알게 된 기술자를 소개하고, 소비자 요구와 현장 정보를 전달할 수 있다. 그러나 해당 작업의 계약 당사자나 현장관리자가 되지 않는다.

### 실제 흐름

1. 지랭이 필요한 공종과 기술자 후보를 설명한다.
2. 소비자가 기술자에게 직접 범위와 견적을 확인한다.
3. 소비자가 기술자와 직접 작업일·금액·책임을 정하고 직접 지급한다.
4. 소비자가 작업자를 선택하고, 맞지 않으면 작업 중단·교체 여부도 직접 결정한다.
5. 지랭은 자기 목공과 맞물리는 치수·순서·의도를 전달하지만 타 공종 작업자를 고용·지휘하지 않는다.
6. 타 공종의 하자·지연·추가금은 소비자와 해당 기술자가 직접 해결한다.

소개비를 받는다면 숨은 공사 마진이 아니라 사전에 공개된 방식이어야 한다. 초기 모델에서는 소개 자체보다 **목공일 안의 정보 전달**로 한정하는 편이 이 시스템의 투명성과 더 잘 맞는다.

## 7. 책임과 통제의 선

| 항목 | 소비자 | 지랭 / 힌지앤룰 | 개별 기술자 |
|---|---|---|---|
| 전체 공사 여부·예산 | 최종 결정 | 목공 관점의 선택지 설명 | 자기 공종 견적 |
| 자재 주문·결제 | 직접 수행 | 목록·수량·대체안 산출 | 필요 규격 전달 |
| 목공 작업 | 작업일 승인·지급 | 직접 수행 | 해당 없음 |
| 타 공종 계약·지급 | 직접 수행 | 당사자 아님 | 직접 계약·수령 |
| 작업자 선택·교체 | 직접 결정 | 후보 정보 전달 | 자기 계약에 따름 |
| 전체 일정·현장관리 | 소비자가 직접 결정하거나 별도 담당자 선임 | 맡지 않음 | 자기 일정만 확약 |
| 목공 치수·스케치 | 현장에서 확인 | 작성·수정·전달 | 관련 부분 확인 |
| 목공 작업상 문제 | 지랭과 직접 협의 | 직접 수행 범위 책임 | 해당 없음 |
| 타 공종 하자 | 해당 기술자와 해결 | 보증하지 않음 | 자기 공종 책임 |
| 구조·전기·소방·가스 등 | 적격자 직접 선임 | 필요성을 알리고 제외 | 자격 범위 책임 |

지랭이 전체 공정을 지휘하고, 모든 기술자를 선정·교체하며, 총공사비를 받고, 공사 완성을 약속하면 문구와 관계없이 다시 총괄도급으로 읽힐 수 있다. 따라서 **돈·지시·선택·하자 처리의 흐름이 실제로 소비자와 각 기술자에게 직접 이어져야 한다.**

## 8. 최소 기록 — 계약을 키우지 않되 없애지도 않는다

구두로 시작해도 합의는 법적으로 계약이 될 수 있다. 그러므로 `계약 자체를 하지 않는다`고 홍보하지 않는다. 대신 공사 전체를 묶은 도급계약을 받지 않고, 매 작업일의 범위와 정산을 짧게 남긴다.

필요 기록:

1. `목공 작업일 확인` — 날짜, 장소, 일당, 시간, 그날 가능한 일
2. `현장 결정 기록` — 소비자가 선택한 치수·재료·변경
3. `자재 직접주문 확인` — 주문·결제 주체와 납기
4. `가구 제작 확인` — 치수·마감·수량·납품·허용오차
5. `기술자 직접거래 안내` — 힌지앤룰이 계약 당사자·보증인이 아님
6. `추가 작업일 확인` — 변경 이유와 예상 작업일

이 기록은 긴 공사계약서가 아니라, 책임을 다시 지랭 한 사람에게 몰아넣지 않기 위한 모바일 한 장 기록이다.

## 9. 소비자에게 생기는 가치

- 설계자에게 설명한 뒤 다시 목수에게 번역하는 손실이 줄어든다.
- 현장에서 치수와 요구를 함께 확인하므로 수정이 빠르다.
- 큰 기획비가 필요 없는 작은 공사도 전문가의 판단을 사용할 수 있다.
- 필요 없는 공종과 자재를 줄일 가능성이 커진다.
- 자재 가격과 기술자 인건비가 소비자에게 그대로 보인다.
- 작업자가 맞지 않을 때 소비자가 직접 교체를 판단할 수 있다.
- 소비자가 직접 참여하고 싶은 현장에서 특히 강하다.
- 가구·목공·공간 판단이 끊기지 않아 결과의 일관성이 높아진다.

이 시스템의 장점은 단순히 싸다는 것이 아니다.

> 소비자가 돈과 선택권을 쥐고, 설계 가능한 목수가 현장에서 필요한 판단과 제작을 바로 연결한다.

## 10. 누구에게 맞는가

### 잘 맞는 현장

- 기획비가 부담스럽지만 아무 계획 없이 시작하고 싶지는 않은 소규모 공사
- 가구와 목공이 중심인 매장·작업실·주거 공간
- 소비자가 현장에 참여하고 빠르게 선택할 수 있는 공사
- 기존 공간을 크게 부수기보다 고쳐 쓰는 공사
- 예산과 자재를 직접 확인하고 싶은 소비자
- 전체 인테리어 업체보다 경험 많은 목수의 판단이 필요한 현장

### 받지 않는 현장

- 전체 공사 총액과 완공일을 힌지앤룰이 보증해야 하는 현장
- 타 공종을 지랭이 고용·지휘·정산해야 하는 현장
- 무제한 도면 수정과 무료 견적을 요구하는 현장
- 구조·대수선·용도변경·법정 설계 또는 전기·소방·가스 전문 책임을 대신 요구하는 현장
- 소비자는 현장에 관여하지 않으면서 모든 결정을 지랭에게 넘기는 현장
- 자재비와 작업자 비용을 힌지앤룰이 모아 집행하길 요구하는 현장

## 11. 피드 전환 서사

피드는 `새 디자인 서비스 출시`가 아니라 **일하는 방식의 재정의**를 보여준다.

| 12 | FROM MAKING TO SYSTEM | 현장 판단을 기록·구조화하는 방식이 AI 연구로 이어짐 |

개인적 소진의 사실은 숨기지 않되 `책임을 피한다`가 중심 문장이 되어서는 안 된다.

> 공사를 통째로 파는 대신, 내가 가장 잘하는 현장 판단과 목공을 하루 단위로 투명하게 제공한다.

- 타 공종의 일정·하자·감정 노동이 지랭에게 되돌아오지 않는가
- 소비자가 직접 결정하면서도 설계 품질은 높아지는가
- 작은 공사에서 실제 문의와 반복 작업이 생기는가
- 현장·가구 수익이 AFTON·FORMUTE·AI 연구를 지속할 시간을 남기는가
- 지랭이 다음 날 다시 움직일 수 있을 만큼 에너지가 남는가

## 15. 법률·세무 확인사항

이 문서는 사업전략안이며 개별 거래의 법률·세무 판단을 대신하지 않는다.

- 「건설산업기본법」상 도급은 명칭과 관계없이 건설공사의 완성을 약정하고 그 결과에 대가를 지급하기로 하는 계약이다. 따라서 일당제라는 이름만으로 도급성이 사라지지 않는다. [국가법령정보센터 건설산업기본법](https://www.law.go.kr/LSW/lsInfoP.do?lsId=001808)
- 「근로기준법」은 근로자와 근로계약을 실제 근로 제공과 임금 지급 관계로 정의한다. 소비자의 구체적 지휘 아래 일하는 구조라면 `독립 목수`라는 명칭만으로 근로관계 가능성이 사라지지 않는다. [국가법령정보센터 근로기준법 제2조](https://www.law.go.kr/LSW//lsLawLinkInfo.do?chrClsCd=010202&lsId=001872&lsJoLnkSeq=1000090438&print=print)
- 국세청은 고용관계 또는 유사 계약 아래 제공한 노동의 대가를 근로소득, 고용관계 없이 독립적으로 계속 제공하는 용역의 대가를 사업소득으로 구분한다. [국세청 근로소득의 범위](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=8165&mi=6582)
- 건축·대수선·용도변경·법정 리모델링, 전기·소방·가스 등은 별도 자격과 책임 검토가 필요하다. 목공 현장 스케치와 법정 설계를 혼동하지 않는다.

파일럿 전에 전문가가 실제 거래 흐름을 보고 다음 둘 중 무엇인지 판정해야 한다.

1. 소비자가 작업일별로 직접 고용하는 일용근로 관계
2. 독립된 목수가 작업일수 기준으로 용역을 제공하는 사업 관계

두 경우 모두 필요한 신고·보험·세금·기록이 다르다. `계약이 없다`거나 `일용직이다`라는 자의적 표현으로 결정하지 않는다.
