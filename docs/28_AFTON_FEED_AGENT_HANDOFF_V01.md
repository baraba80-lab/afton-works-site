## 3. AFTON visual grammar

Core tension: precise editorial structure + unstable perception.

Use:
- strong editorial hierarchy
- large type, cropped type, occasional occlusion
- image/text overlap
- asymmetric layouts
- abrupt scale changes
- raw/high-contrast color fields, including primary or acidic accents where appropriate
- dense archive/index views alternating with sparse image-led scenes
- layered relation cards and connection logic when showing scent/material relationships
- photography that can feel tactile, strange, lived-in, or difficult to identify

Avoid:
- generic beige luxury-perfume minimalism
- generic bottle-on-pedestal hero photography
- flowers/fog/skin clichés used as default fragrance shorthand
- generic AI gradients
- molecular/atom diagrams as decoration
- forced nostalgia
- making every post look like the selected first photograph
- a 9-grid puzzle that only works when viewed on the profile
- retyping or approximating the official afton. wordmark

Reference behavior, not literal copying:
- Bureau Borsche: strict editorial order with one authored break
- Teenage Engineering: clear information hierarchy and modular grammar
- onformative: ambiguous forms and perceptual exploration
- FIELD: controlled relationships between data/form/surface
- Ffern: archive/time/return as information architecture only

## 5. Twenty-feed visual sequence

### ACT 1 / APPEARANCE
01. Selected blurred portrait — image-led opening, no explanatory design.
02. Color interruption — hard color field + oversized cropped type; intentionally unlike 01.
03. Near / far — same subject or material at radically different scale.
04. Seam — two unrelated images meet at one visible boundary; overlap or misregistration is the point.
05. Issue cover — AFTON issue/index cover, dense editorial information, official wordmark used correctly.

### ACT 2 / MATERIAL
06. One material, too close — macro/tactile material image, no bottle hero.
07. Name larger than object — material name dominates, physical evidence is small.
08. Concentration / distance study — one material shown as a visual sequence of changing intensity; do not expose a real formula unless approved.
09. Time trace — opening / middle / drydown represented as three visual states, not a perfume pyramid cliché.
10. Relation map — one scent/material connected to related article, record, object or reference through a clear modular layout.

### ACT 3 / DEVELOPMENT
11. Working table — real notes, samples, cards or controlled reconstruction of a development desk.
12. Candidate set — three sample identities shown as a comparison system, not three finished products.
13. Delta — a before/after adjustment screen showing that a scent was changed, without publishing protected exact formula data.
14. Measure — weighing / pipette / label / stock-identification detail; operational precision becomes visual language.
15. Freeze — formula revision becomes final for this session; show version/record identity, not pseudo-scientific spectacle.

### ACT 4 / WORKSHOP EXPERIENCE
16. Before visit — customer direction/image/reference selection as a visual board.
17. Smell / choose — human decision moment; focus on hands, materials, sample codes and relation, not lifestyle-model advertising.
18. Final 50 mL — final object appears only after the development sequence. Avoid standard luxury bottle hero treatment.
19. Personal archive — formula/revision/history/reorder identity shown as an archive object.
20. Next issue / reopen — return to a strong image-led scene that opens the next cycle rather than closing the brand.

## 6. Feed rhythm

Do not make 20 isolated pretty posters. Build a profile rhythm:
- image-heavy
- hard typography
- material evidence
- index/archive
- image-heavy
- system/relationship
- development evidence
- human decision
- final object

No three consecutive posts should use the same composition logic.

Each post must still work alone. The feed may gain meaning as a sequence, but no tile should depend on neighboring tiles to become readable.
