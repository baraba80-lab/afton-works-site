# AFTON — Concept Sheet Specification

## Purpose
The concept sheet is a decision document, not a moodboard dump. It must show what AFTON is learning, which original visual language is winning, and what should be built into the temporary landing page.

The sheet is assembled only after browser-based research and generation following `docs/06_HIGGSFIELD_BROWSER_EXECUTION.md`.

---

# 1. Required sections

## A. Header
- `afton.`
- `Familiar, but not identifiable.`
- `Structure is precise. Perception is slightly unstable.`
- current round / date

## B. Reference lessons
Show a small number of research references with source attribution.

For each reference:
- source / studio
- URL
- one thing to study
- one thing not to copy

References are research-only and must be visually separated from AFTON original outputs.

## C. AFTON original studies
Show every generated study from the current round with:
- prompt ID
- family
- filename
- visible model / format
- KEEP / DEVELOP / REJECT
- one-line curatorial note

## D. Visual system observations
Record what is becoming consistent across good outputs:
- dominant background tone
- material vocabulary
- contrast level
- field density
- transparency behavior
- edge behavior
- negative-space behavior
- anomaly scale
- image-to-type relationship

Do not prematurely turn observations into permanent numeric design tokens.

## E. Crop tests
For every KEEP candidate show at minimum:
- desktop 16:9 hero crop
- desktop crop with large left-side typography zone
- mobile 9:16 crop or adaptation
- small card crop

A visually strong image that fails crops cannot become the landing hero.

## F. Decision panel
Conclude with:
- winning family or families
- rejected families
- why
- next prompt IDs
- whether a new generation round is necessary

# 3. Layout guidance

The concept sheet itself should already behave like AFTON:
- strict grid
- warm neutral ground
- large typographic scale contrast
- minimal annotation
- one anomaly maximum per page or frame
- reference material visually marked as `REFERENCE ONLY`
- original AFTON material visibly marked as `AFTON STUDY`

Do not use decorative moodboard collage styling.

Recommended board logic:
1. statement
2. references
3. six probes
4. scoring
5. three finalists
6. crop tests
7. decision

---

# 4. Scoring table

Use a 1–5 score for:
- AFTON specificity
- ambiguity
- material credibility
- cliché resistance
- negative space
- desktop crop
- mobile crop
- typography compatibility
- web compression potential
- emotional aftertone

Add total score only as a secondary aid. A high total does not override a clear conceptual mismatch.

---

# 5. Production boundary

The concept sheet may contain external reference screenshots for internal review, with attribution.

The public site may not use those reference images unless separately cleared for use.

Only approved AFTON original outputs move from:
`public/assets/concept/higgsfield/`

to a later production asset directory.

Never treat a generated study as approved merely because it exists.
