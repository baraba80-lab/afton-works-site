# AFTON Website — Project Status

## Current stage
Concept lock → temporary landing visual development.

## Immediate target
Publish a temporary AFTON landing screen before building the full system.

The first public page must establish:
- `afton.` wordmark presence
- visual tone
- core statement
- a first Scent Field / perceptual image
- a minimal contact or status path

## Current constraints
- Initial equipment budget is limited.
- The final personalized scent system will require staged implementation.
- The site must remain light enough to load quickly.
- Heavy realtime graphics are postponed.
- FMOC2 integration is a later phase.

## Long-term target
AFTON Studio eventually becomes a precomputed custom-fragrance workshop:
1. Customer pays online.
2. Research begins immediately.
3. Commercial fragrance references, population reviews, and customer perception are compared.
4. The system estimates a personal perceptual offset / starting point.
5. Several scent tracks are prepared before the visit.
6. The customer visits, smells, fine-adjusts, blends, and takes the sealed product home.
7. Product packaging records blend date, packing date, and recommended opening date.
8. Post-opening feedback recalibrates the customer's scent passport and the system.

## Experience concept
The workshop and website are an **investigation into something that cannot yet be named**.

Population perception and personal perception are both valid data. A mismatch is not an error. It is a clue.
