## R01 — Studio Dumbar / DEMO 2019
SOURCE: https://studiodumbar.com/work/demo

WHAT TO STUDY
- identity that remains legible while a variable rule distorts it
- controlled variation rather than random variation
- a strong fixed structure carrying many changing states

WHAT NOT TO COPY
- DEMO letterforms
- orange / dark-blue palette
- cursor-distortion behavior itself

AFTON APPLICATION
- define one stable AFTON frame and allow only one visual variable to move at a time
- use this logic for `Scent Field`, crop changes, and repeated states

MOTIF TAGS: `CONTROLLED_VARIATION`, `STABLE_IDENTITY`, `ONE_VARIABLE`

## R02 — FIELD.IO / Scalable Storytelling
SOURCE: https://field.io/work/scalable-storytelling

WHAT TO STUDY
- a visual library decomposed into form, texture and depth, then rebuilt as a coherent generative system
- large variation without losing system identity

WHAT NOT TO COPY
- specific architectural source imagery
- the studio's exact tool UI or generated visual treatment

AFTON APPLICATION
- treat perfume/material/reference imagery as a visual library whose properties become rules, not collage pieces
- extract texture, transparency, density, edge and depth as reusable variables

MOTIF TAGS: `LIBRARY_TO_SYSTEM`, `PARAMETRIC_COHESION`, `SOURCE_DECOMPOSITION`

## R03 — FIELD.IO / IBM Think 2020
SOURCE: https://field.io/work/ibm-think-2020

WHAT TO STUDY
- multiple data channels independently affecting shape, colour, surface and movement
- simultaneous layered perception instead of one event = one graphic
- expressive free form inside a disciplined system

WHAT NOT TO COPY
- IBM palette
- ribbon forms
- music-reactive implementation

AFTON APPLICATION
- map scent properties to separate visual behaviors: density, diffusion, persistence, dryness, warmth
- several subtle variables may coexist while the page composition remains quiet

MOTIF TAGS: `MULTI_LAYER_FIELD`, `DATA_TO_BEHAVIOR`, `SIMULTANEOUS_PERCEPTION`

# First-pass motif clusters

## M01 — CONTROLLED VARIATION
References: R01, R02, R04

AFTON meaning: one system, many states. Variation is rule-based and still identifiable as AFTON.

## M02 — DATA BECOMES BEHAVIOR
References: R03, R05

AFTON meaning: numbers disappear into density, edge, spacing, diffusion, persistence and trace.

## M03 — AMBIGUOUS CENTER / DELAYED RECOGNITION
References: R06

AFTON meaning: show a perceptual object or state before naming it. Recognition arrives late.

## M04 — ORDER + ONE CONTRADICTION
References: R08, R09

AFTON meaning: hierarchy is clear; one event is slightly wrong, displaced or unexpectedly vivid.

## M05 — AMBIENT RESIDUE
References: R07

AFTON meaning: motion is slow and environmental. The trace matters more than spectacle.

## M06 — ARCHIVE / RETURN / TIME
References: R10

AFTON meaning: previous states remain visible and influence the next visit, scent or decision.
