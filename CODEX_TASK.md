## Phase A — reference collection only

### Step 1 — visit seeded references
Use browser control to visit the sources already listed in `research/REFERENCE_MANIFEST.md`.

Primary goal: understand **design logic**, not collect pretty moodboard images.

For each useful capture, record:
- source/studio
- exact page URL
- local screenshot path
- motif tag
- what the frame proves
- what AFTON may borrow as a rule
- what must not be copied

### Step 2 — capture 12–18 frames
Capture 12–18 useful reference frames total.

Save screenshots only under:
`research/reference-only/`

Do not place third-party reference images in `public/`.

Prioritize frames that demonstrate:
- controlled variation
- library → system transformation
- data → visual behavior
- ambiguous center / delayed recognition
- editorial order + one contradiction
- functional hierarchy
- ambient residue
- archive / return / time

Avoid collecting multiple near-identical frames from the same project.

### Step 3 — update manifest
Update:
`research/REFERENCE_MANIFEST.md`

The manifest should end with a shortlist of **8–12 strongest reference frames**, grouped by the six motifs in `docs/11_DESIGN_MOTIF_LIBRARY_V01.md`.

### Step 4 — motif reduction
Create:
`docs/12_MOTIF_REVIEW_CURRENT.md`

For each motif M01–M06, record:
- supporting reference frames
- strength for AFTON
- risk of cliché / copying
- relevance to temporary landing
- KEEP / DEVELOP / DROP

Recommend no more than **4 primary motifs** for the temporary landing.

Stop after the motif review.
